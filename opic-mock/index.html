시험 안내 · Orientation

  • 실제 오픽처럼 컴퓨터 목소리(Ava)가 영어로 문제를 읽어 줍니다. 문제 글자는 보이지 않아요.
  • 문제는 다시 듣기 1번만 가능합니다.
  • 문제가 끝나면 바로 녹음이 시작돼요. 한 문제당 최대 2분.
  • 다 말했으면 다음 문제를 누르세요. 한 번 넘어가면 돌아갈 수 없어요.
  • 문제는 12~15개, 1번은 자기소개입니다.
  • 조용한 곳에서, 가능하면 이어폰·헤드셋을 쓰세요.
  • 시험 중에는 메모, 검색, 다른 사람의 도움을 쓰지 않습니다.
